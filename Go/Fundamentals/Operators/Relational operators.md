# 4. Relational Operators

# What are Relational Operators?

Used to compare values.

Result is always:

```text
true or false
```

---

# Relational Operators Table

| Operator | Meaning               |
| -------- | --------------------- |
| `==`     | Equal to              |
| `!=`     | Not equal             |
| `>`      | Greater than          |
| `<`      | Less than             |
| `>=`     | Greater than or equal |
| `<=`     | Less than or equal    |

---

# Equal To (`==`)

```go
fmt.Println(10 == 10)
```

Output:

```text
true
```

---

# Not Equal (`!=`)

```go
fmt.Println(5 != 3)
```

Output:

```text
true
```

---

# Greater Than (`>`)

```go
fmt.Println(10 > 5)
```

Output:

```text
true
```

---

# Less Than (`<`)

```go
fmt.Println(2 < 1)
```

Output:

```text
false
```

---

# Real-World Use Cases

Used in:

* Login systems
* Blockchain validation
* API authentication
* Conditional statements
* Smart contracts

---

# Example

```go
age := 18
fmt.Println(age >= 18)
```
