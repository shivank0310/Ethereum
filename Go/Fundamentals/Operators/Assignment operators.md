# 7. Assignment Operators

# What are Assignment Operators?

Used to assign or update values.

---

# Assignment Operators Table

| Operator | Meaning             |
| -------- | ------------------- |
| `=`      | Assign              |
| `+=`     | Add and assign      |
| `-=`     | Subtract and assign |
| `*=`     | Multiply and assign |
| `/=`     | Divide and assign   |
| `%=`     | Modulus and assign  |

---

# Basic Assignment (`=`)

```go
x := 10
```

---

# Add and Assign (`+=`)

```go
x := 5
x += 3
```

Equivalent to:

```go
x = x + 3
```

---

# Output

```text
8
```

---

# Subtract and Assign (`-=`)

```go
x -= 2
```

---

# Multiply and Assign (`*=`)

```go
x *= 4
```

---

# Why Assignment Operators Matter

Makes code:

* Cleaner
* Shorter
* Easier to read
